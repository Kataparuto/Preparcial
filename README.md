Aplicación web de comercio electrónico construida con Next.js (App Router), TypeScript y Tailwind CSS que consume la API pública de DummyJSON para mostrar un catálogo de productos.


Catálogo principal — listado de productos con miniatura, nombre, categoría, precio y stock.

Detalle de producto — información extendida: fotografía, categoría/marca, precio, stock y descripción.

Carrito global — carrito con estado, que se mantiene sincronizado entre el catálogo y el detalle.

Header persistente — visible en todas las rutas, con enlace a la tienda y contador de artículos en el carrito.
